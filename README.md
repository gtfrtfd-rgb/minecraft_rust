# Minecraft Rust

[![Build](https://github.com/gtfrtfd-rgb/minecraft_rust/actions/workflows/build.yml/badge.svg)](https://github.com/gtfrtfd-rgb/minecraft_rust/actions/workflows/build.yml)

Воксельная игра в стиле Minecraft, написанная на **Rust** с использованием движка **Bevy**.

> 🤖 **Весь код этого проекта полностью написан искусственным интеллектом** — от генерации мира до ИИ мобов. Никакой ручной работы программиста.

---

## ✨ Возможности

### 🌍 Мир
- **Процедурная генерация** — Perlin-шум, биомы, рельеф, деревья
- **5 биомов** — равнины, лес, пустыня, снег, горы
- **2 типа деревьев** — дуб (раскидистый) и сосна (ёлка)
- **Туман расстояния** — скрывает границу мира
- **Невидимые барьеры** — нельзя выйти за пределы
- **Автосохранение** — RLE-сжатие + JSON каждые 30 секунд

### 🎮 Геймплей
- **DDA-рейкаст** — точное определение блока под прицелом
- **Ломание блоков с удержанием** — контур блока плавно меняет цвет (чёрный → оранжевый → красный), затем блок исчезает
- **Установка блоков** — ПКМ, мгновенно
- **9 блоков в хотбаре** — трава, земля, камень, булыжник, песок, дерево, листва, доски, кирпич
- **Физика игрока** — гравитация, прыжки, бег, приседание, полёт
- **Bunny-hop** — зажми Space для автопрыжков
- **Coyote time + jump buffer** — отзывчивое управление

### 🐷 Мобы
- **4 типа** — свинья, овца, корова, курица
- **Пиксельные текстуры в стиле MC** — процедурный атлас 4×4 (16×16 тайлов), шум в стиле оригинального Minecraft
- **Процедурные меши** — тело, голова, глаза, пятачок, рога, гребень, клюв
- **Двухслойные глаза** — тёмный зрачок + светлая окантовка (белок), как в MC
- **Белые пятна на корпусе** — у коровы, асимметрично, как в оригинале
- **AI на 4 состояния** — Idle / Wander / Alert / Flee
- **Реагируют на игрока**:
  - Замечают в радиусе 6–9 блоков
  - Смотрят, отворачиваются, ходят вокруг
  - Убегают после удара
- **Анимация ног** при ходьбе
- **Обход препятствий** — прыгают через блоки, разворачиваются у стен
- **Расталкивание** — не слипаются в кучу
- **Смерть и удаление** — при HP = 0 моб исчезает

### 🔊 Звуки
Всё **процедурное** — WAV-файлы генерируются в память при запуске, никаких внешних ассетов.
- **Разные звуки ломания по материалам** — камень «крак», дерево «ток», стекло «дзинь», кирпич «клац», трава «пуф»
- **Случайный питч 0.8–1.0 при ломании и установке** — как в MC, чтобы звуки не повторялись
- **Разные звуки шагов по материалам** — цок по камню, тук по дереву, шуршание по песку, глухой шорох по траве
- **4 варианта каждого звука шага** — не звучат однообразно
- **Непрерывный звук при движении** — шаги накладываются друг на друга, пока идёшь
- **Отдельный звук в присяде** — тише в 3 раза, питч выше, шаги реже
- **Звук приземления после прыжка** — ниже тоном, громче обычного шага, зависит от высоты падения
- **Звук удара по мобу** — «шлёпок» с разбросом питча

### 🎨 Интерфейс
- **Главное меню** — при старте
- **Меню паузы** — по Esc (Продолжить / Выйти в меню / Выйти из игры)
- **Хотбар** — 9 слотов с номерами
- **HUD** — координаты, FPS,
- **Прицел** — белый крестик в центре
- **Подсветка блока под прицелом** — чёрный контур

## 🎮 Управление

| Клавиша | Действие |
|---|---|
| W A S D / стрелки | Движение |
| Мышь | Обзор |
| Space | Прыжок (зажми — автопрыжок) |
| Ctrl | Бег |
| Shift | Присесть / спуск в полёте |
| F | Полёт (вкл/выкл) |
| ЛКМ (удержание) | Ломать блок / ударить моба |
| ПКМ | Поставить блок |
| 1 – 9 | Выбор слота |
| Колесо мыши | Переключение слотов |
| Esc | Пауза / меню |

## 🛠 Установка (для разработки)

### Требования

- **Rust** — установить с [rustup.rs](https://rustup.rs)
- **MSVC Build Tools** (Windows) — скачать с [visualstudio.microsoft.com](https://visualstudio.microsoft.com)

> ℹ️ Сборка настроена только под **Windows** (см. CI). Для сборки на Linux/macOS потребуется добавить Linux-зависимости (Bevy) и расширить матрицу в `.github/workflows/build.yml`.

### Сборка и запуск

    git clone https://github.com/gtfrtfd-rgb/minecraft_rust.git
    cd minecraft_rust
    cargo run --release

Первая сборка — 5–15 минут. Последующие — 30 сек – 2 мин.

## 💾 Сохранения

Игра автоматически сохраняет мир:

- Каждые 30 секунд
- При выходе (Esc → Выйти из игры)

Файлы в папке saves/ рядом с .exe:

- saves/world.bin — RLE-сжатые блоки (~180 KB)
- saves/meta.json — сид, позиция игрока, режим

**Начать новый мир** — удалить папку saves/.

## 🔊 Как устроен звук

Никаких внешних `.wav` — все звуки синтезируются при запуске.

1. **На Startup** `GameAudioPlugin` генерирует PCM-сэмплы для 4 материалов ломания, 4 материалов шагов (по 4 варианта каждого), установки, удара по мобу.
2. Сэмплы кодируются в WAV-байты через `hound` и заворачиваются в `AudioSource` **прямо в памяти** (без файловой системы).
3. Хендлы лежат в ресурсе `SoundHandles`, а системы `interaction/breaking.rs` и `player/footsteps.rs` спавнят `AudioPlayer` с нужным питчем и громкостью.

Синтез — это шумовой LCG + синусоидальные моды с разными огибающими. Разный характер материалов достигается фильтрацией (low-pass / high-pass) и набором резонансных частот.
