## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | движение |
| Мышь | обзор |
| Space | прыжок (зажми — автопрыжок) |
| Ctrl | бег |
| Shift | присесть |
| F | полёт |
| ЛКМ | сломать блок |
| ПКМ | поставить блок |
| 1-9 / колесо | слот |
| Esc | выход |
